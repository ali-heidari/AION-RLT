# Code Conventions

This file documents the code and generation conventions for AI agents in this repository.

Key conventions
- Prefer small, runnable code examples with exact file paths.
- Avoid inventing build or runtime details when no manifest exists.
- Preserve minimal changes and keep the implementation focused.
- Use the root `README.md` as the adoption reference for the overall standard.

Guidance for generated code
- Create only the files required to solve the task.
- When generating new files, include a small runnable example or usage snippet.
- If a repo already has a package manifest, use it. If not, ask before inventing one.
