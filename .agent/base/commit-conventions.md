# Commit Conventions

Use this format for commit messages in this repository.

Commit message template
- `type(scope): short summary`
- Blank line
- `Body (optional)`
- Blank line
- `Refs: #<issue>`

Allowed types
- `feat`
- `fix`
- `chore`
- `docs`
- `ci`
- `style`
- `refactor`
- `test`

Examples
- `fix(parser): correct markdown folding issue`
- `docs(readme): update adoption section`

When updating standards
- Update `README.md` and the related convention markdown files together.
